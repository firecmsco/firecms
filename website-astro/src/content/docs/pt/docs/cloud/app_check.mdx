FireCMS Cloud pode exigir o Firebase App Check em cada requisição que seu painel de administração faz ao Firestore e ao Storage, de modo que apenas o seu próprio CMS possa ler ou escrever seus dados, e não uma chave de API copiada ou um script extraído do seu bundle.

O App Check é um serviço do Firebase. Esta página cobre como integrá-lo ao FireCMS; para saber o que o App Check faz e quais provedores de atestação existem, consulte [a documentação do App Check do Firebase](https://firebase.google.com/docs/app-check).

:::caution
Lembre-se de adicionar o domínio `app.firecms.co` à lista de domínios permitidos na configuração do provedor AppCheck.
:::

Você pode habilitar o Firebase App Check no seu app diretamente nas **configurações do projeto** no console FireCMS Cloud,
ou fornecendo a prop `appCheck` na configuração do seu app.

Ao implementar em código, você pode ter mais controle sobre a configuração e o provedor que deseja usar,
incluindo provedores personalizados.

Você pode definir algumas opções:
- `provider`: O provedor que deseja usar.
- `isTokenAutoRefreshEnabled`: Se deve atualizar automaticamente o token.
- `debugToken`: Um token de debug a usar.
- `forceRefresh`: Se deve forçar a atualização de um token.


## Provedores

A propriedade `provider` é obrigatória e deve ser uma instância de um provedor Firebase AppCheck.
Você pode usar um dos seguintes provedores:

### ReCaptchaEnterpriseProvider

Para configurar o ReCaptchaEnterpriseProvider, você precisa criar uma nova chave de site reCAPTCHA Enterprise.
Siga as instruções na [documentação do Firebase](https://firebase.google.com/docs/app-check/web/recaptcha-enterprise-provider).

:::caution
Certifique-se de ter adicionado o domínio `app.firecms.co` à lista de domínios permitidos no console reCAPTCHA Enterprise.
:::

```tsx
import {FireCMSAppConfig} from "@firecms/cloud";
import {ReCaptchaEnterpriseProvider} from "@firebase/app-check";

const appConfig: FireCMSAppConfig = {

    version: "1",

    appCheck: {
        provider: new ReCaptchaEnterpriseProvider("your-site-key")
    },
}

export default appConfig;
```

### ReCaptchaV3Provider

Para configurar o ReCaptchaV3Provider, você precisa criar uma nova chave de site reCAPTCHA v3.
Siga as instruções na [documentação do Firebase](https://firebase.google.com/docs/app-check/web/recaptcha-provider).

```tsx
import {FireCMSAppConfig} from "@firecms/cloud";
import {ReCaptchaV3Provider} from "@firebase/app-check";

const appConfig: FireCMSAppConfig = {

    version: "1",

    appCheck: {
        provider: new ReCaptchaV3Provider("your-site-key")
    },
}

export default appConfig;
```

### Provedor personalizado

Você também pode criar um provedor personalizado implementando a interface `AppCheckProvider`.


## Verifique sua configuração

O FireCMS Cloud fornece o Firebase App Check ao seu código, então o provider que você cria usa a
mesma cópia do SDK que o próprio FireCMS. Para isso, duas coisas são necessárias:

- **Importe de `@firebase/app-check`**, como nos exemplos acima, não de `firebase/app-check`. Apenas
  os imports que nomeiam exatamente um pacote compartilhado recebem a cópia do FireCMS. Um import de
  `firebase/app-check` faz o build apontar para um arquivo que ele nunca gera, e o app mostra
  "Error loading remote config".
- **Mantenha `@firebase/app-check` na seção `shared`** do plugin de federation no seu
  `vite.config.ts`. O template do FireCMS Cloud já o inclui.

A seção `shared` do template é assim. `generate: false` significa que o seu build não inclui nenhuma
cópia do pacote e usa a que o FireCMS fornece:

```ts
federation({
    name: "remote_app",
    filename: "remoteEntry.js",
    exposes: {
        "./config": "./src/index"
    },
    shared: {
        "react": { generate: false },
        "react-dom": { generate: false },
        "react/jsx-runtime": { generate: false },
        "react/jsx-dev-runtime": { generate: false },
        "@firecms/cloud": { generate: false },
        "@firecms/core": { generate: false },
        "@firecms/firebase": { generate: false },
        "@firecms/ui": { generate: false },
        "@firebase/firestore": { generate: false },
        "@firebase/app": { generate: false },
        "@firebase/functions": { generate: false },
        "@firebase/auth": { generate: false },
        "@firebase/storage": { generate: false },
        "@firebase/analytics": { generate: false },
        "@firebase/remote-config": { generate: false },
        "@firebase/app-check": { generate: false },
    }
})
```

Para o arquivo completo, veja o
[`vite.config.ts` do template do FireCMS Cloud](https://github.com/firecmsco/firecms/blob/main/packages/cli/templates/template_cloud/vite.config.ts).
