FireCMS Cloud può imporre Firebase App Check su ogni richiesta che il tuo pannello admin invia a Firestore e Storage, così solo il tuo CMS può leggere o scrivere i tuoi dati, e non una chiave API copiata o uno script estratto dal tuo bundle.

App Check è un servizio Firebase. Questa pagina spiega come integrarlo in FireCMS; per sapere cosa fa App Check e quali provider di attestazione esistono, consulta [la documentazione App Check di Firebase](https://firebase.google.com/docs/app-check).

:::important
Ricorda di aggiungere il dominio `app.firecms.co` all'elenco dei domini consentiti nella configurazione del provider AppCheck.
:::

Puoi abilitare Firebase App Check nella tua app direttamente nelle **impostazioni del progetto** nella console FireCMS Cloud, o fornendo la prop `appCheck` nella configurazione della tua app.

Implementandolo nel codice, hai più controllo sulla configurazione e sul provider che vuoi usare, inclusi i provider personalizzati.

Puoi definire alcune opzioni:
- `provider`: Il provider che vuoi usare.
- `isTokenAutoRefreshEnabled`: Se aggiornare automaticamente il token.
- `debugToken`: Un token di debug da usare.
- `forceRefresh`: Se forzare un aggiornamento del token.


## Provider

La proprietà `provider` è richiesta e deve essere un'istanza di un provider Firebase AppCheck.
Puoi usare uno dei seguenti provider:

### ReCaptchaEnterpriseProvider

Per configurare il ReCaptchaEnterpriseProvider, devi creare una nuova chiave del sito reCAPTCHA Enterprise.
Segui le istruzioni nella [documentazione Firebase](https://firebase.google.com/docs/app-check/web/recaptcha-enterprise-provider).

:::important
Assicurati di aver aggiunto il dominio `app.firecms.co` all'elenco dei domini consentiti nella console reCAPTCHA Enterprise.
:::

```tsx
import {FireCMSAppConfig} from "@firecms/cloud";
import {ReCaptchaEnterpriseProvider} from "@firebase/app-check";

const appConfig: FireCMSAppConfig = {

    version: "1",

    appCheck: {
        provider: new ReCaptchaEnterpriseProvider("your-site-key")
    },
}

export default appConfig;
```

### ReCaptchaV3Provider

Per configurare il ReCaptchaV3Provider, devi creare una nuova chiave del sito reCAPTCHA v3.
Segui le istruzioni nella [documentazione Firebase](https://firebase.google.com/docs/app-check/web/recaptcha-provider).

```tsx
import {FireCMSAppConfig} from "@firecms/cloud";
import {ReCaptchaV3Provider} from "@firebase/app-check";

const appConfig: FireCMSAppConfig = {

    version: "1",

    appCheck: {
        provider: new ReCaptchaV3Provider("your-site-key")
    },
}

export default appConfig;
```

### Provider personalizzato

Puoi anche creare un provider personalizzato implementando l'interfaccia `AppCheckProvider`.


## Verifica la tua configurazione

FireCMS Cloud fornisce Firebase App Check al tuo codice, così il provider che crei usa la stessa copia
dell'SDK di FireCMS. Servono due cose:

- **Importa da `@firebase/app-check`**, come negli esempi sopra, non da `firebase/app-check`. Solo
  gli import che nominano esattamente un pacchetto condiviso ricevono la copia di FireCMS. Un import da
  `firebase/app-check` fa puntare la build a un file che non produce mai, e l'app mostra
  "Error loading remote config".
- **Mantieni `@firebase/app-check` nella sezione `shared`** del plugin di federation nel tuo
  `vite.config.ts`. Il template di FireCMS Cloud lo include già.

La sezione `shared` del template è così. `generate: false` significa che la tua build non contiene
alcuna copia del pacchetto e usa quella fornita da FireCMS:

```ts
federation({
    name: "remote_app",
    filename: "remoteEntry.js",
    exposes: {
        "./config": "./src/index"
    },
    shared: {
        "react": { generate: false },
        "react-dom": { generate: false },
        "react/jsx-runtime": { generate: false },
        "react/jsx-dev-runtime": { generate: false },
        "@firecms/cloud": { generate: false },
        "@firecms/core": { generate: false },
        "@firecms/firebase": { generate: false },
        "@firecms/ui": { generate: false },
        "@firebase/firestore": { generate: false },
        "@firebase/app": { generate: false },
        "@firebase/functions": { generate: false },
        "@firebase/auth": { generate: false },
        "@firebase/storage": { generate: false },
        "@firebase/analytics": { generate: false },
        "@firebase/remote-config": { generate: false },
        "@firebase/app-check": { generate: false },
    }
})
```

Per il file completo, vedi il
[`vite.config.ts` del template di FireCMS Cloud](https://github.com/firecmsco/firecms/blob/main/packages/cli/templates/template_cloud/vite.config.ts).
